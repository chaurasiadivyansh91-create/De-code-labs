# AI Recommendation System

## Overview
This project is a simple AI Recommendation System built using Python. It recommends items based on user interests using similarity matching.

## Features
- Takes user input
- Matches user preferences
- Displays recommendations
- Uses CSV dataset
- Simple recommendation logic

## Technologies Used
- Python
- Pandas
- CSV

## Folder Structure
AI-Recommendation system/
├── recommendation.py
├── requirements.txt
├── README.md
└── dataset/
    └── recommendation.csv

## How to Run
1. Install Python.
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run:
   ```
   python recommendation.py
   ```
