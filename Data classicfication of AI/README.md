# Data Classification using AI

## Project Overview
This project demonstrates how Artificial Intelligence can classify data into different categories based on input features. It is developed as part of my AI Internship at De Code Labs.

## Objective
- Learn data classification concepts.
- Build a simple AI classification model.
- Understand data preprocessing and prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Project Structure
- README.md
- classification.py
- dataset.csv

## Dataset Description

The project uses a CSV dataset (dataset.csv) containing sample records for data classification. The dataset includes multiple input features and a target class (label). The machine learning model is trained using this data to classify new records into the appropriate category.

## How to Run

1. Install Python 3.x on your computer.
2. Install the required libraries:
   pip install pandas scikit-learn
3. Place dataset.csv and classification.py in the same folder.
4. Run the program:
   python classification.py
5. The program will train the model and display the classification results.

## Output
The model predicts the class of new input data based on the trained dataset.
