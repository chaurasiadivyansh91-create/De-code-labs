🤖 AI Chatbot using Python

A simple rule-based AI chatbot developed using Python as part of my AI Internship at De Code Labs. The chatbot interacts with users through predefined responses and demonstrates the fundamentals of conversational AI using conditional statements and loops.

---

📌 Project Overview

This project simulates a basic chatbot that responds to common user queries such as greetings, asking about the bot, current date and time, and general conversation. It is designed to showcase core Python programming concepts and chatbot logic.

---

✨ Features

- 💬 Interactive text-based conversation
- 👋 Responds to greetings
- 😊 Answers basic questions
- 📅 Displays the current date
- ⏰ Displays the current time
- 🤖 Provides chatbot information
- ❓ Handles unknown inputs with a default response
- 🚪 Exit option to end the conversation

---

🛠️ Technologies Used

- Python 3
- "datetime" module
- Conditional Statements ("if-elif-else")
- Loops ("while")
- Functions

▶️ How to Run

1. Install Python 3 on your system.
2. Clone this repository or download the project.
3. Open a terminal in the project folder.
4. Run the following command:

python chatbox.py
